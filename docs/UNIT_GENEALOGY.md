# Árvore genealógica das tropas

Este documento registra as combinações permitidas no Cruzador e será preenchido conforme as receitas forem definidas.

## Regras atuais

- O Cruzador recebe exatamente duas tropas próprias enviadas com botão direito.
- As tropas precisam chegar à construção para serem consumidas.
- A descendente aparece no tile livre mais próximo do Cruzador; a população dos pais é preservada. Se não houver espaço, os pais aguardam junto à construção.
- Uma nova ordem de movimento cancela uma entrega pendente.
- Enquanto não houver receita cadastrada para um par, vale o fallback provisório descrito em [GAME_DESIGN.md](GAME_DESIGN.md): nasce uma `Tropa Combinada` com os atributos agregados dos pais.
- A ordem dos pais ainda não foi definida como significativa ou irrelevante.
